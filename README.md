# Personnel IDA Project

This is a **beginner-friendly project** created as a first step into **Data Analytics**. The goal is to practice working with data in a structured way—cleaning it, exploring it, and understanding patterns—using Python inside a Jupyter Notebook.

---

## 📌 Project Overview
The project focuses on a dataset related to **personnel (employees/individual records)**.  
You will learn how to:
1. Import data into Python.  
2. Perform basic **data cleaning** (handling missing values, correcting formats, etc.).  
3. Explore the dataset using **descriptive statistics and visualizations**.  
4. Gain insights from the data to build confidence in analytical thinking.  

This is not about advanced machine learning yet—it’s about building a **solid foundation** in data handling and interpretation.

---

## 🛠 Tools Used
- **Python 3**  
- **Jupyter Notebook**  
- Libraries:  
  - `pandas` → data handling  
  - `numpy` → numerical operations  
  - `matplotlib` & `seaborn` → data visualization  

---
